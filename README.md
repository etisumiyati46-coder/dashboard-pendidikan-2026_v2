# Dashboard Crosscutting Pendidikan Kabupaten Karawang 2026

Dashboard statis (HTML + Chart.js) berisi alur Permasalahan > Sasaran > Indikator/Target > Rencana Aksi > Perangkat Daerah > Anggaran.

## Ubah data
Edit `data.js` (anggaran dalam Rp juta). Data bawaan hanya contoh.

## Publikasi di GitHub Pages
1. Buat repositori baru di GitHub, lalu unggah `index.html`, `data.js`, dan `README.md`.
2. Buka Settings > Pages, pilih Source: Deploy from a branch, Branch: main, folder: / (root), lalu Save.
3. Tunggu 1-2 menit. Alamatnya: https://USERNAME.github.io/NAMA-REPO/
